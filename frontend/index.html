Model

Mathematical Model

Differential Equations

dx/dt = vx, dy/dt = vy

Position changes according to velocity.

Distance

d = √((xe − x)² + (ye − y)²)

People move toward an available exit.

Crowd Density

ρ = N / A

People per unit area.

Density-Dependent Speed

v(ρ) = v0(1 − ρ / ρmax)

Movement speed decreases as density rises.

Euler Method

xn+1 = xn + Δt · vx

yn+1 = yn + Δt · vy

RK4 Method

Uses four intermediate slope estimates.

A higher-order numerical integration method.
